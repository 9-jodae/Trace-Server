# 장애 연락 흐름

- 회사: 모아온

- 작성 부서: 개발팀
- 작성자: 한지후

## 제1조 알림

장애를 발견하면 개발팀 당직자에게 즉시 알린다. [[문서 지식 지도]]에서 복구 절차를 찾는다.

## 제2조 시간

당직자는 30분 내 초기 대응을 시작한다. 보안 사고는 《보안 사고 대응 절차》 제2조를 우선한다.

## 제3조 종료

복구 완료 후 팀장에게 요약을 전달하고 인수인계 기록을 갱신한다.

## 표 1 연락

| 상황 | 첫 연락 |
| --- | --- |
| 일반 장애 | 개발팀 당직 |
| 보안 사고 | 개발팀 당직·보안 담당 |
| 고객 영향 | 영업팀 담당 |
