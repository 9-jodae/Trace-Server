# 연차 운영 지침

- 회사: 모아온
- 문서 번호: leave-operation / v1
- 작성 부서: 인사팀
- 작성자: 최하린
- 작성일: 2026-04-15

## 제1조 적용 대상

이 지침은 인사팀의 연차 정산 업무에 적용한다. 전사 공개용 《취업규칙》 제12조와 수치가 일치하지 않으므로 대외 안내에는 사용하지 않는다.

## 제2조 이월 처리

인사팀 정산 시 미사용 연차는 다음 연도로 최대 7일 이월한다. 이월분은 다음 해 6월 30일까지 사용한다. 충돌 해소 전에는 인사팀이 인사 책임자에게 확인한다.

## 제3조 예외

장기 휴직자는 복귀일 기준으로 사용 기한을 다시 산정한다. 예외 처리는 인사팀 기록에 사유를 남긴다.
