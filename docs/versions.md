# Pinned versions

Checked against official project sources on 2026-11-04:

- Spring Boot 4.1.2: https://docs.spring.io/spring-boot/system-requirements.html
- Kotlin 2.3.21: generated by Spring Initializr for Spring Boot 4.1.2 (https://start.spring.io/)
- Gradle 9.8.2: https://github.com/gradle/gradle/blob/master/released-versions.json
- springdoc 3.2.0 for Boot 4: https://github.com/springdoc/springdoc-openapi
- MinIO Java SDK 9.0.3: https://github.com/minio/minio-java/releases
- pgvector 0.8.7 PostgreSQL 18 image: https://github.com/pgvector/pgvector#docker
- ktlint Gradle plugin 14.2.0: https://plugins.gradle.org/plugin/org.jlleitschuh.gradle.ktlint
- Testcontainers 2.0.5: https://java.testcontainers.org/

Kotlin 2.4.21 is the latest stable release (https://github.com/JetBrains/kotlin/releases/tag/v2.4.21), but ktlint Gradle plugin 14.2.0 fails to parse Kotlin 2.4 source and Gradle scripts (`Extensions storage is not registered`). This repository pins one stable step lower, 2.3.21, matching Spring Initializr. Container images and dependencies are fixed to versions, not `latest`.
